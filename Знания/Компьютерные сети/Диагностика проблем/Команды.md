
telnet <ip свитча> - заходим на свитч
sh ports - смотрим состояние линка
sh fdb po <порт свитча> - проверяем мак абонента
sh fdb mac_address <мак адрес по порту> - смотрим мак абонента и сверяем с тем что в карточке
sh err ports<номер порта> - смотрим на физические ошибки CRC error
sh log - проверяем на флапы и рибуты (влучение выключение устройства абонента)
sh pac po - смотрим трафик абонента: системный или активный
sh uti po - проверяем на флуды (большое количество широковещательных пакетов)
sh arpentry - смотрим кэш arp, ищем магистральный порт(Dynamic) по маку
sh fdb mac_address - ищем порт магистрального свитча
sh ports - проверяем магистральный порт на линк
sh err ports - проверяем магистральный порт на ошибки

Кофиг

Sh fdb ports **  - если несколько маков и аланов магистральный, конфигурировать нельзя
config ports ** state disable - гасим порт
config ports ** state enable - вкл порт
config ports * speed capability_advertised  - настраиваем скорость на порту
sh port_security ports- указываем мак адреса хостов которым разрешено передавать линию через порт
На абонентских портах везде должен быть порт секьюрити: config port_security ports  admin_state enable max_learning_addr action drop lock_address_mode deleteontimeout
show vlan ports * - смотрим влан на порту абонента на портах абонента влан должен быть тренированный(VID)
config vlan vlanid  номер влад delete * номер порта - Если меняем айпи на внешний меняем влан
config vlan vlanid  номер влана add untagged * номер порта - накидываем влан на порт
save - в конце сохраняем
cabel_diag ports * - видим тип кабеля
